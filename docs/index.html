What it catches

Seven AST- and pattern-based checks aimed squarely at the shape of careless AI output — the dangerous calls, the leaked keys, the imports that don't exist.

high

hallucinated-imports

Imports your interpreter can't resolve — like import fastjson — the classic AI confabulation, with a hint on what to do about it.

critical

dangerous-calls

eval/exec on non-literals, os.system, shell=True, pickle deserialization, unsafe yaml.load() — the stuff that becomes an incident.

critical

secrets

AWS keys, GitHub tokens, OpenAI-style keys and hardcoded passwords. Placeholders are skipped, and findings are redacted in the report.

medium

weak-error-handling

Bare except: blocks and swallowed exceptions that hide failures until production explains them to you.

medium

network-safety

HTTP calls with no timeout, verify=False TLS bypasses, and unverified SSL contexts.

medium

risky-deps

Typosquatted packages in your requirements — requets instead of requests — plus unpinned dependencies.

low

ai-tells

Leftover "rest of the code goes here" placeholder comments and pasted mega-lines that signal nobody finished the job.

ci-ready

built for pipelines

JSON output, severity filters, and exit codes designed so a CI job can fail the build exactly when it should.

Install & use

Python 3.9+ and nothing else. AIGuard has zero third-party dependencies — there's nothing to audit in the auditor.

# install pip install . # or, isolated: pipx install . # scan a directory (recursive) aiguard scan ./src # scan one file, machine-readable JSON aiguard scan app.py --json # only medium+, and fail CI on high+ aiguard scan ./src --min-severity medium --fail-on high

Drop it into CI

Exit codes do the talking: 0 = pass, 2 = findings at or above --fail-on (default high), 1 = usage error. One workflow file and every PR gets audited.

# .github/workflows/aiguard.yml name: AIGuard on: [push, pull_request] jobs: audit: runs-on: ubuntu-latest steps: - uses: actions/checkout@v4 - uses: actions/setup-python@v5 with: python-version: "3.12" - run: pip install . - run: aiguard scan . --fail-on high

Honest limitations

AIGuard is a heuristic sanity check, not a proof of safety.

  • Python only — it parses the Python AST, so other languages are out of scope.
  • Heuristics miss things — exotic secret formats can slip by, and the typosquat list covers ~40 popular packages.
  • Run it in your venv — import resolution is only as accurate as the environment you scan in.
  • It won't catch logic bugs. It catches the shape of careless AI output before that output ships.
